# Code for "Traveling waves in a model for cortical spreading depolarization with slow–fast dynamics"
This repository contains the source code and scripts used to generate the materials and results presented in:

Traveling waves in a model for cortical spreading depolarization with slow–fast dynamics
David Reyner-Parra; Carles Bonet; Teresa M. Seara; Gemma Huguet
Chaos 33, 083154 (2023).
DOI: https://doi.org/10.1063/5.0160509

# Purpose
This repository is provided solely as a consultative and archival resource associated with the published paper. It is not intended to serve as an actively developed software project. The repository may receive occasional updates to add or clarify code associated with the study.

Its purpose is to document the computational procedures underlying the results presented in the manuscript and to facilitate inspection of the code used to generate the corresponding figures.

# Reproducibility
The repository currently contains the scripts and functions used to generate Figures 1 and 2 of the published paper:
  - Figure 1: generated using neuron_astrocyte_RLee_script.m
  - Figure 2: generated using red_nan_script.m

# Requirements
The code was originally developed, tested and executed using:
  - Matlab R2018b.
